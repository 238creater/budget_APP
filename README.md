# 家計簿アプリ

スマートフォン利用を想定した、インストール不要の静的 Web 家計簿です。

## 起動方法

`index.html` をブラウザで開くと利用できます。

## 主な機能

- 支出・収入の登録
- カテゴリ追加
- メモ入力
- 月別の収入、支出、残高表示
- カレンダーで日別支出を確認
- カテゴリ別の円グラフ
- 前月とのカテゴリ別支出比較
- レシート画像の確認と、読み取りテキストから候補作成
- レシート候補の金額、日付、カテゴリ、メモ編集
- メモやカテゴリによる記録検索
- 固定費の登録と月ごとの自動追加
- JSON の書き出しと読み込み

データはブラウザの `localStorage` に保存されます。
